# LinguaVox — Use Cases

Real-world scenarios where LinguaVox eliminates the language tax and accelerates typing.

---

## Non-Native Speakers & Multilingual Professionals

**Problem:** Every message in a second language carries a hidden tax — a pause before sending. "Is this grammatically correct? Does this sound natural?" Multiply by hundreds of messages a day across email, Slack, Jira, CRM.

**With LinguaVox:**
- Speak your native language → output arrives in any of 21 target languages, polished and professional
- Or speak English naturally and let "Grammar Fix" or "Smart Polish" clean up errors
- Works in Gmail, Outlook Web, Slack, and any email composer

**Example:** Speak Ukrainian → output: professional English in Gmail. Speak Spanish → output: German in Slack.

## Customer Support Agents

**Problem:** Support agents spend hours typing repetitive responses in Zendesk, Intercom, Freshdesk, or Salesforce. Repetitive typing leads to RSI and fatigue.

**With LinguaVox:**
- Dictate ticket responses directly into support tool fields
- Use "Business Style" enhancement to auto-polish casual speech into professional support language
- Handle 3x more tickets per hour without additional typing strain

**Platforms:** Salesforce, Zendesk, Freshdesk, Intercom, Jira Service Management

## People with RSI or Mobility Challenges

**Problem:** Repetitive strain injury makes extended typing painful. Standard browser voice input is unreliable and inconsistent.

**With LinguaVox:**
- Full voice replacement for keyboard typing in any browser-based workflow
- Works on all major platforms without per-site activation
- Hold-to-talk UX eliminates accidental transcription

## Multilingual Teams

**Problem:** Teams with members across different languages need to communicate in a common language. Composing in a second language is slow.

**With LinguaVox (Organization plan):**
- Each team member speaks in their native language
- Translation mode converts to the team's common language
- Shared API key pool managed by org admin — no per-user OpenAI account needed
- Usage analytics in the team dashboard

## Language Learning

**Problem:** Learners need to practice composing text in a target language but lack confidence.

- Immediate feedback loop between spoken attempt and written correction
- Works in any language learning platform's text fields
