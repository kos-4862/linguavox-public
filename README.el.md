## Τι είναι το LinguaVox;

Το LinguaVox είναι μια επέκταση Chrome για υπαγόρευση φωνής και μετάφραση με τεχνητή νοημοσύνη. Κράτα Ctrl+Space, μίλα, άφησε — το μεταγραμμένο κείμενο εμφανίζεται αμέσως στο ενεργό πεδίο: συνομιλία, email, φόρμα CRM, σχόλιο στο Jira, μπλοκ στο Notion. Η επέκταση χρησιμοποιεί OpenAI Whisper για ακρίβεια 95%+ και GPT-4o-mini για προαιρετική βελτίωση κειμένου: διόρθωση γραμματικής, αλλαγή ύφους, μετάφραση.

Σε αντίθεση με τα περισσότερα εργαλεία υπαγόρευσης, το LinguaVox δεν απαιτεί δικό σου κλειδί API OpenAI. Οι δωρεάν χρήστες λαμβάνουν 20 αιτήματα ημερησίως από το κοινόχρηστο σύνολο — χωρίς καμία διαμόρφωση. Οι προχωρημένοι χρήστες και οι ομάδες μπορούν να συνδέσουν το δικό τους κλειδί για απεριόριστη χρήση.

**v3.0 — Λειτουργία Σύσκεψης:** μεταφρασμένοι υπότιτλοι σε πραγματικό χρόνο για Google Meet, Zoom, Teams και οποιαδήποτε κλήση μέσω προγράμματος περιήγησης. Ο ήχος της καρτέλας καταγράφεται μέσω Chrome API → αποστέλλεται στο Deepgram → οι υπότιτλοι εμφανίζονται ως κινούμενο επίστρωμα.

## Πώς λειτουργεί

**Πριν το LinguaVox:** άνοιγμα ξεχωριστής εφαρμογής → εγγραφή → αντιγραφή → εναλλαγή στο πρόγραμμα → επικόλληση  
**Με το LinguaVox:**

```
1. Κάνε κλικ σε οποιοδήποτε πεδίο web (Slack, Gmail, Notion, Jira…)
2. Κράτα  Ctrl+Space  →  μίλα
3. Άφησε  →  το κείμενο εμφανίζεται σε ~3 δευτερόλεπτα  ✓
```

Χωρίς αντιγραφή-επικόλληση. Χωρίς εναλλαγή εφαρμογών. Σε οποιοδήποτε ιστότοπο.

## Κύρια χαρακτηριστικά

- **Δεν απαιτείται κλειδί API** — 20 αιτήματα/ημέρα δωρεάν από κοινόχρηστο σύνολο
- **Φέρε το δικό σου κλειδί** — απεριόριστη χρήση στο κόστος OpenAI
- **Λογαριασμοί οργανισμού** — κοινόχρηστο σύνολο κλειδιών, διαχείριση μελών, ανάλυση χρήσης
- **21+ γλώσσες** — μεταγραφή + μετάφραση σε ένα βήμα
- **6 λειτουργίες βελτίωσης ΤΝ** — διόρθωση γραμματικής, επαγγελματικό ύφος, ακαδημαϊκό, ανεπίσημο, δημιουργικό, έξυπνο γυάλισμα
- **Λειτουργία Σύσκεψης** — υπότιτλοι σε πραγματικό χρόνο μέσω Deepgram
- **Προστασία απορρήτου** — ο ήχος φωνής δεν αποθηκεύεται ποτέ
- **Κάτω από 3 δευτερόλεπτα** — από την ομιλία έως την εισαγωγή κειμένου
- **Ακρίβεια 95%+** — OpenAI Whisper

## Συχνές ερωτήσεις

**Λειτουργεί το LinguaVox στο Slack;**  
Ναι. Το Slack υποκλέπτει συμβάντα πληκτρολογίου σε επίπεδο σελίδας. Το LinguaVox καταχωρεί τη συντόμευση σε επίπεδο προγράμματος περιήγησης μέσω `chrome.commands.onCommand`, παρακάμπτοντας την καταγραφή του Slack.

**Χρειάζομαι κλειδί API OpenAI;**  
Όχι. Οι δωρεάν χρήστες λαμβάνουν 20 αιτήματα/ημέρα. Πρόσθεσε το δικό σου κλειδί στον πίνακα ελέγχου για απεριόριστη χρήση.

**Η φωνή μου καταγράφεται ή αποθηκεύεται;**  
Όχι. Ο ήχος επεξεργάζεται σε πραγματικό χρόνο από το Whisper και διαγράφεται άμεσα. Μηδέν δεδομένα φωνής διατηρούνται.

**Ποιες γλώσσες υποστηρίζονται;**  
21+ γλώσσες: ελληνικά, αγγλικά, ουκρανικά, ρωσικά, ισπανικά, γαλλικά, γερμανικά, ιαπωνικά, κορεατικά, κινεζικά, αραβικά, πορτογαλικά, ιταλικά, πολωνικά, ολλανδικά, τουρκικά, σουηδικά, ρουμανικά, τάγκαλογκ, ούρντου, παντζαμπικά και άλλες.

## Εγκατάσταση

**Επιλογή Α — Chrome Web Store (συνιστάται):**
1. [Chrome Web Store →](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea) — κάνε κλικ "Προσθήκη στο Chrome"
2. Κάνε κλικ στο εικονίδιο LinguaVox → "Σύνδεση με Google"
3. Πάτα Ctrl+Space οπουδήποτε και αρχίστε να μιλάτε

**Επιλογή Β — Χειροκίνητη εγκατάσταση (ZIP):**
1. Κατέβασε `linguavox-3.0.0.zip` από [Releases →](https://github.com/kos-4862/linguavox-public/releases/latest)
2. Αποσυμπίεσε σε φάκελο
3. Chrome → `chrome://extensions` → ενεργοποίησε "Λειτουργία προγραμματιστή" → "Φόρτωση αποσυμπιεσμένης επέκτασης" → επέλεξε το φάκελο
