## LinguaVox ਕੀ ਹੈ?

LinguaVox ਇੱਕ Chrome ਐਕਸਟੈਨਸ਼ਨ ਹੈ ਜੋ AI ਆਵਾਜ਼ ਡਿਕਟੇਸ਼ਨ ਅਤੇ ਅਨੁਵਾਦ ਲਈ ਹੈ। Ctrl+Space ਦਬਾਓ, ਬੋਲੋ, ਛੱਡੋ — ਟ੍ਰਾਂਸਕ੍ਰਾਈਬਡ ਟੈਕਸਟ ਤੁਰੰਤ ਸਰਗਰਮ ਫੀਲਡ ਵਿੱਚ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ: ਚੈਟ, ਈਮੇਲ, CRM ਫਾਰਮ, Jira ਵਿੱਚ ਟਿੱਪਣੀ, Notion ਵਿੱਚ ਬਲਾਕ। ਐਕਸਟੈਨਸ਼ਨ 95%+ ਸ਼ੁੱਧਤਾ ਲਈ OpenAI Whisper ਅਤੇ ਵਿਕਲਪਿਕ ਟੈਕਸਟ ਸੁਧਾਰ ਲਈ GPT-4o-mini ਵਰਤਦੀ ਹੈ।

ਜ਼ਿਆਦਾਤਰ ਡਿਕਟੇਸ਼ਨ ਟੂਲਸ ਦੇ ਉਲਟ, LinguaVox ਨੂੰ ਆਪਣੀ OpenAI API key ਦੀ ਲੋੜ ਨਹੀਂ। ਮੁਫ਼ਤ ਉਪਭੋਗਤਾ ਸਾਂਝੇ ਪੂਲ ਤੋਂ ਪ੍ਰਤੀ ਦਿਨ 20 ਬੇਨਤੀਆਂ ਪ੍ਰਾਪਤ ਕਰਦੇ ਹਨ — ਬਿਨਾਂ ਕਿਸੇ ਸੰਰਚਨਾ ਦੇ। ਉੱਨਤ ਉਪਭੋਗਤਾ ਅਤੇ ਟੀਮਾਂ ਅਸੀਮਤ ਵਰਤੋਂ ਲਈ ਆਪਣੀ key ਜੋੜ ਸਕਦੇ ਹਨ।

**v3.0 — ਮੀਟਿੰਗ ਮੋਡ:** Google Meet, Zoom, Teams ਅਤੇ ਕਿਸੇ ਵੀ ਬ੍ਰਾਊਜ਼ਰ-ਆਧਾਰਿਤ ਕਾਲ ਲਈ ਰੀਅਲ-ਟਾਈਮ ਅਨੁਵਾਦਿਤ ਸਬਟਾਈਟਲ। ਟੈਬ ਆਡੀਓ Chrome API ਰਾਹੀਂ ਕੈਪਚਰ ਕੀਤੀ ਜਾਂਦੀ ਹੈ → Deepgram ਨੂੰ ਭੇਜੀ ਜਾਂਦੀ ਹੈ → ਸਬਟਾਈਟਲ ਫਲੋਟਿੰਗ ਓਵਰਲੇ ਵਜੋਂ ਦਿਖਾਈ ਦਿੰਦੇ ਹਨ।

## ਇਹ ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ

**LinguaVox ਤੋਂ ਪਹਿਲਾਂ:** ਵੱਖਰੀ ਐਪ ਖੋਲੋ → ਰਿਕਾਰਡ ਕਰੋ → ਕਾਪੀ ਕਰੋ → ਬ੍ਰਾਊਜ਼ਰ ਤੇ ਜਾਓ → ਪੇਸਟ ਕਰੋ  
**LinguaVox ਨਾਲ:**

```
1. ਕਿਸੇ ਵੀ ਵੈੱਬ ਫੀਲਡ ਵਿੱਚ ਕਲਿੱਕ ਕਰੋ (Slack, Gmail, Notion, Jira…)
2. Ctrl+Space ਦਬਾਓ ਅਤੇ ਰੱਖੋ  →  ਬੋਲੋ
3. ਛੱਡੋ  →  ~3 ਸਕਿੰਟਾਂ ਵਿੱਚ ਟੈਕਸਟ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ  ✓
```

ਕੋਈ ਕਾਪੀ-ਪੇਸਟ ਨਹੀਂ। ਕੋਈ ਐਪ ਸਵਿਚਿੰਗ ਨਹੀਂ। ਕਿਸੇ ਵੀ ਵੈੱਬਸਾਈਟ ਤੇ।

## ਅਕਸਰ ਪੁੱਛੇ ਜਾਂਦੇ ਸਵਾਲ

**ਕੀ LinguaVox Slack ਤੇ ਕੰਮ ਕਰਦਾ ਹੈ?**  
ਹਾਂ। Slack ਪੇਜ ਲੈਵਲ ਤੇ ਕੀਬੋਰਡ ਇਵੈਂਟਸ ਕੈਪਚਰ ਕਰਦਾ ਹੈ। LinguaVox `chrome.commands.onCommand` ਰਾਹੀਂ ਬ੍ਰਾਊਜ਼ਰ ਲੈਵਲ ਤੇ ਹਾਟਕੀ ਰਜਿਸਟਰ ਕਰਦਾ ਹੈ, Slack ਦੀ ਕੈਪਚਰਿੰਗ ਨੂੰ bypass ਕਰਦਾ ਹੈ।

**ਕੀ ਮੈਨੂੰ OpenAI API key ਦੀ ਲੋੜ ਹੈ?**  
ਨਹੀਂ। ਮੁਫ਼ਤ ਉਪਭੋਗਤਾ ਸਾਂਝੇ ਪੂਲ ਤੋਂ ਪ੍ਰਤੀ ਦਿਨ 20 ਬੇਨਤੀਆਂ ਪ੍ਰਾਪਤ ਕਰਦੇ ਹਨ। ਅਸੀਮਤ ਵਰਤੋਂ ਲਈ ਡੈਸ਼ਬੋਰਡ ਵਿੱਚ ਆਪਣੀ key ਜੋੜੋ।

**ਕੀ ਮੇਰੀ ਆਵਾਜ਼ ਰਿਕਾਰਡ ਜਾਂ ਸਟੋਰ ਕੀਤੀ ਜਾਂਦੀ ਹੈ?**  
ਨਹੀਂ। ਆਡੀਓ Whisper ਦੁਆਰਾ ਰੀਅਲ-ਟਾਈਮ ਵਿੱਚ ਪ੍ਰੋਸੈਸ ਕੀਤੀ ਜਾਂਦੀ ਹੈ ਅਤੇ ਤੁਰੰਤ ਮਿਟਾ ਦਿੱਤੀ ਜਾਂਦੀ ਹੈ। ਕੋਈ ਆਵਾਜ਼ ਡੇਟਾ ਸਟੋਰ ਨਹੀਂ ਹੁੰਦਾ।

**ਕਿਹੜੀਆਂ ਭਾਸ਼ਾਵਾਂ ਸਮਰਥਿਤ ਹਨ?**  
21+ ਭਾਸ਼ਾਵਾਂ: ਪੰਜਾਬੀ, ਅੰਗਰੇਜ਼ੀ, ਯੂਕਰੇਨੀ, ਰੂਸੀ, ਸਪੇਨੀ, ਫ੍ਰੈਂਚ, ਜਰਮਨ, ਜਾਪਾਨੀ, ਕੋਰੀਅਨ, ਚੀਨੀ, ਅਰਬੀ, ਪੁਰਤਗਾਲੀ, ਇਤਾਲਵੀ, ਪੋਲਿਸ਼, ਡੱਚ, ਤੁਰਕੀ, ਸਵੀਡਿਸ਼, ਰੋਮਾਨੀਅਨ, ਯੂਨਾਨੀ, ਫਿਲੀਪੀਨੀ, ਉਰਦੂ ਅਤੇ ਹੋਰ।
